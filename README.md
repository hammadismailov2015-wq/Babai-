# Учимся омовению

Приложение для обучения малому омовению (вуду), полному омовению (гусль) и таяммуму.
Доводы взяты из Корана и Сунны, в приложении сравниваются мнения четырёх мазхабов.

**Открыть:** https://hammadismailov2015-wq.github.io/Babai-/

## Что внутри

- **Уроки по шагам** для вуду (11 шагов), гусля (12) и таяммума (6). На фигуре подсвечивается часть тела, на которую льётся вода, а в таяммуме — земля. У каждого шага есть довод с источником. Хадисы из аль-Бухари и Муслима помечены как «сахих».
- **Выбор мазхаба** (Ханафи, Малики, Шафии, Ханбали). Под выбранный мазхаб перестраиваются пометки «фард / ваджиб / сунна» в шагах, список фардов, список того, что нарушает омовение, и правильные ответы в тестах.
- **Интерактивный аят 5:6.** Нажатие на арабское слово переводит урок к нужному шагу. Есть пояснение, почему «ва-арджуля-кум» связано с омыванием, а не с протиранием.
- **Мазхабы:** 25 спорных вопросов с решением каждой школы и доводами сторон.
- **Правила:** условия обязательности и действительности, вода, что нарушает омовение, истинджа, масх по хуфам, сунны.
- **Для женщин:** волосы и платок, косметика, хайд, нифас, истихада. Пометки для женщин есть и в шагах уроков.
- **Словарь:** 33 термина с арабским написанием и поиском.
- **Проверка:** тест для мужчин, тест для женщин и тренировка порядка действий.
- **Режим «у раковины»:** крупный текст, счётчик «1-2-3» для повторов, экран не гаснет. Можно включить озвучку шагов на русском и прослушать дуа на арабском.
- **Установка на телефон и работа без интернета** (PWA). При отправке ссылки в мессенджере показывается карточка-превью.

Прямые ссылки на разделы: `#learn`, `#ghusl`, `#tayammum`, `#women`, `#rules`, `#madhab`, `#glossary`, `#quiz-men`, `#quiz-women`, `#practice`. На конкретный спорный вопрос: `#m-niyyah`, `#m-head`, `#m-touch` и т. д.

## Как устроено

- Всё приложение — один файл `index.html` без сборки и зависимостей: HTML, CSS и обычный JavaScript.
- Шрифты подключаются из Google Fonts: Prata, Commissioner и Amiri для арабского.
- `sw.js` — service worker. Страницу он сначала загружает из сети, а без интернета отдаёт из кэша.
- `manifest.webmanifest` и `icons/` — иконки и данные для установки на телефон.
- Светлая и тёмная темы переключаются автоматически, по настройке телефона.
- Прогресс уроков и выбранный мазхаб хранятся в `localStorage` браузера.

Данные (шаги, доводы, мнения мазхабов, вопросы тестов) лежат в начале `<script>` в виде массивов. Их можно править, не трогая разметку.

## Важно

Номера хадисов и формулировки мнений подготовлены по известным сборникам и книгам фикха, но перед широким распространением их стоит проверить у знающего человека. Исправления приветствуются.
